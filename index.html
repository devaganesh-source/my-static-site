Cloud Platform Security, Compliance & Operational Resilience RFP

1. Independent Assurance and Regulatory Compliance

1.1 SOC Independent Assurance: Identify the platform's current SOC attestation, including the report type and the Trust Services Categories covered, and explain how authorized customers may obtain supporting documentation.

1.2 Information Security Certification: State whether the platform maintains a current ISO 27001 certification, identify the applicable version of the standard, and describe how customers can access the certificate.

1.3 GDPR and International Data Transfers: Describe the platform's support for GDPR obligations, including technical and organizational measures, breach notification, subprocessor protections, data-subject requests, and mechanisms for international transfers.

1.4 Payment Card Compliance: Describe the platform's PCI DSS posture, the current PCI DSS version addressed, available merchant and service-provider attestations, and the division of responsibility between the vendor and its customers.

1.5 Healthcare Data Protection: Explain how the platform supports HIPAA-regulated workloads, including safeguards for protected health information, breach-notification commitments, Business Associate Agreement availability, and any relevant plan conditions.

1.6 Data Privacy Framework: State whether the vendor participates in recognized data privacy frameworks for transfers involving the European Union, United Kingdom, and Switzerland, and identify where public certification evidence can be verified.

2. Data Protection and Infrastructure Security

2.1 Encryption Controls: Specify the algorithms and protocol versions used to protect customer data at rest and in transit, and describe any option for isolated runtime infrastructure.

2.2 Cloud Infrastructure and Production Access: Describe the platform's primary cloud infrastructure, geographic footprint, identity and access management controls for production resources, and production change-control process.

3. Resilience, Recovery, and Security Assurance

3.1 Regional Resilience: Explain how the platform responds to a regional cloud outage, including traffic failover behavior, data replication, and recurring resilience testing.

3.2 Backup and Recovery: Describe customer-data backup frequency, retention period, geographic replication, storage separation, restoration testing, and deletion behavior.

3.3 Security Testing and Continuous Assurance: Describe the vendor's penetration-testing program, code-review and static-analysis practices, continuous cloud-security scanning, and monitoring of production resilience.

4. Current Operational Evidence

4.1 Live Service Health: Using an official live operational source, report the platform's current overall service status, active-incident count, and the publisher's latest status-update timestamp.
